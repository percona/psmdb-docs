# Percona Server for MongoDB feature comparison

Percona Server for MongoDB 7.0 is based on [MongoDB Community Edition 7.0](https://docs.mongodb.com/manual/introduction/) and extends it with the functionality, that is otherwise only available in MongoDB Enterprise Edition.

|                             | PSMDB                                                                                                                                                                                            | MongoDB                                                                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Storage Engines**         | - [WiredTiger](https://docs.mongodb.org/manual/core/wiredtiger/) (default) - [Percona Memory Engine](https://docs.percona.com/percona-server-for-mongodb/7.0/inmemory.md)                        | - [WiredTiger](https://docs.mongodb.org/manual/core/wiredtiger/) (default) - [In-Memory](https://docs.mongodb.com/v7.0/core/inmemory/) (Enterprise only) |
| **Encryption-at-Rest**      | - Key servers = [Hashicorp Vault](https://docs.percona.com/percona-server-for-mongodb/7.0/vault.md), [KMIP](https://docs.percona.com/percona-server-for-mongodb/7.0/kmip.md) - Fully open source | - Key server = KMIP - Enterprise only                                                                                                                    |
| **Hot Backup**              | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/hot-backup.md) (replica set)                                                                                                       | NO                                                                                                                                                       |
| **LDAP Authentication**     | (legacy) [LDAP authentication with SASL](https://docs.percona.com/percona-server-for-mongodb/7.0/authentication.md)                                                                              | Enterprise only                                                                                                                                          |
| **LDAP Authorization**      | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/authorization.md)                                                                                                                  | Enterprise only                                                                                                                                          |
| **Kerberos Authentication** | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/authentication.md)                                                                                                                 | Enterprise only                                                                                                                                          |
| **AWS IAM authentication**  | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/aws-iam.md)                                                                                                                        | MongoDB Atlas                                                                                                                                            |
| **Audit Logging**           | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/audit-logging.md)                                                                                                                  | Enterprise only                                                                                                                                          |
| **Log redaction**           | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/log-redaction.md)                                                                                                                  | Enterprise only                                                                                                                                          |
| **SNMP Monitoring**         | NO                                                                                                                                                                                               | Enterprise only                                                                                                                                          |
| **Database profiler**       | [YES](https://docs.percona.com/percona-server-for-mongodb/7.0/rate-limit.md) with the [`--rateLimit`](#profiling-rate-limiting) argument                                                         | YES                                                                                                                                                      |

## Profiling Rate Limiting

Profiling Rate Limiting was added to *Percona Server for MongoDB* in v3.4 with the `--rateLimit` argument. Since v3.6, MongoDB Community (and Enterprise) Edition includes a similar option [slowOpSampleRate](https://www.mongodb.com/docs/manual/reference/configuration-options/#mongodb-setting-operationProfiling.slowOpSampleRate). Please see [Profiling Rate Limit](https://docs.percona.com/percona-server-for-mongodb/7.0/rate-limit.md) for more information.
