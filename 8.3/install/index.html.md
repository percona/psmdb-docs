# Quickstart guides

Percona Server for MongoDB is an enhanced, fully compatible, source available, drop-in replacement for MongoDB 8.3 Community Edition with [enterprise-grade features](https://docs.percona.com/percona-server-for-mongodb/8.3/comparison.md).

Find the full list of supported platforms for Percona Server for MongoDB on the [Percona Software and Platform Lifecycle](https://www.percona.com/services/policies/percona-software-platform-lifecycle#mongodb) page.

## Install Percona Server for MongoDB

You can use any of the easy-install guides. We recommend to use **the package manager of your operating system** for a convenient and quick way to install the software for production use. **Use Docker** to try the software first.

**Package manager**

Use the package manager of your operating system to install Percona Server for MongoDB:

[on Debian and Ubuntu](https://docs.percona.com/percona-server-for-mongodb/8.3/install/apt.md) [on RHEL and derivatives](https://docs.percona.com/percona-server-for-mongodb/8.3/install/yum.md) [on Rocky Linux](https://docs.percona.com/percona-server-for-mongodb/8.3/install/rocky-linux.md) [on Amazon Linux 2023](https://docs.percona.com/percona-server-for-mongodb/8.3/install/amazon-linux.md)

We gather [Telemetry data](https://docs.percona.com/percona-server-for-mongodb/8.3/telemetry.md) in Percona packages.

**Docker**

Get our Docker image and spin up Percona Server for MongoDB for a quick evaluation.

Check the Docker guide for step-by-step guidelines.

[Run in Docker](https://docs.percona.com/percona-server-for-mongodb/8.3/install/docker.md)

We gather [Telemetry data](https://docs.percona.com/percona-server-for-mongodb/8.3/telemetry.md) in Docker images.

**Kubernetes**

**Percona Operator for Kubernetes** is a controller introduced to simplify complex deployments that require meticulous and secure database expertise.

Check the Quickstart guides how to deploy and run Percona Server for MongoDB on Kubernetes with Percona Operator for MongoDB.

[Deploy in Kubernetes Quickstart](https://docs.percona.com/percona-operator-for-mongodb/quickstart.html)

**Build from source**

Have a full control over the installation by building Percona Server for MongoDB from source code.

Check the guide below for step-by-step instructions.

[Build from source](https://docs.percona.com/percona-server-for-mongodb/8.3/install/source.md)

**Manual download**

If you need to install Percona Server for MongoDB offline or prefer a specific version of it, check out the link below for a step-by-step guide and get access to the downloads directory.

Note that for this scenario you must make sure that all dependencies are satisfied.

[Install from tarballs](https://docs.percona.com/percona-server-for-mongodb/8.3/install/tarball.md)

## Upgrade instructions

If you are already using MongoDB, see [Upgrading from MongoDB](https://docs.percona.com/percona-server-for-mongodb/8.3/install/upgrade-from-mongodb.md).

If you are running an earlier version of Percona Server for MongoDB, see [Upgrading from Version 8.0](https://docs.percona.com/percona-server-for-mongodb/8.3/install/upgrade-from-80.md).
