# Percona Server for MongoDB 8.3 Documentation

Percona Server for MongoDB is an enhanced, fully compatible, source available, drop-in replacement for MongoDB 8.3 Community Edition with [enterprise-grade features](https://docs.percona.com/percona-server-for-mongodb/8.3/comparison.md).

[To migrate to Percona Server for MongoDB](https://docs.percona.com/percona-server-for-mongodb/8.3/install/upgrade-from-mongodb.md) requires no changes to MongoDB applications or code.

To see which version of Percona Server for MongoDB you are using check the value of the `psmdbVersion` key in the output of the [buildInfo](https://docs.mongodb.com/manual/reference/command/buildInfo/#dbcmd.buildInfo) database command. If this key does not exist, Percona Server for MongoDB is not installed on the server.
