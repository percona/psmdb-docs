# Percona Server for MongoDB feature comparison

Percona Server for MongoDB 8.0 is based on [MongoDB Community Edition 8.0](https://docs.mongodb.com/manual/introduction/) and extends it with the functionality, that is otherwise only available in MongoDB Enterprise Edition.

|                             | PSMDB                                                                                                                                                                                                | MongoDB                                                                                                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Storage Engines**         | - [WiredTiger](https://docs.mongodb.org/manual/core/wiredtiger/) (default) - [Percona Memory Engine](https://docs.percona.com/percona-server-for-mongodb/8.0/inmemory.html)                          | - [WiredTiger](https://docs.mongodb.org/manual/core/wiredtiger/) (default) - [In-Memory](https://docs.mongodb.com/v6.0/core/inmemory/) (Enterprise only) |
| **Encryption-at-Rest**      | - Key servers = [Hashicorp Vault](https://docs.percona.com/percona-server-for-mongodb/8.0/vault.html), [KMIP](https://docs.percona.com/percona-server-for-mongodb/8.0/kmip.html) - Fully open source | - Key server = KMIP - Enterprise only                                                                                                                    |
| **Hot Backup**              | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/hot-backup.html) (replica set)                                                                                                         | NO                                                                                                                                                       |
| **LDAP Authentication**     | (legacy) [LDAP authentication with SASL](https://docs.percona.com/percona-server-for-mongodb/8.0/authentication.html)                                                                                | Enterprise only                                                                                                                                          |
| **LDAP Authorization**      | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/authorization.html)                                                                                                                    | Enterprise only                                                                                                                                          |
| **Kerberos Authentication** | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/authentication.html)                                                                                                                   | Enterprise only                                                                                                                                          |
| **AWS IAM authentication**  | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/aws-iam.html)                                                                                                                          | MongoDB Atlas                                                                                                                                            |
| **Audit Logging**           | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/audit-logging.html)                                                                                                                    | Enterprise only                                                                                                                                          |
| **Log redaction**           | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/log-redaction.html)                                                                                                                    | Enterprise only                                                                                                                                          |
| **SNMP Monitoring**         | NO                                                                                                                                                                                                   | Enterprise only                                                                                                                                          |
| **Database profiler**       | [YES](https://docs.percona.com/percona-server-for-mongodb/8.0/rate-limit.html) with the [`--rateLimit`](#profiling-rate-limiting) argument                                                           | YES                                                                                                                                                      |

## Profiling Rate Limiting

Profiling Rate Limiting was added to *Percona Server for MongoDB* in v3.4 with the `--rateLimit` argument. Since v3.6, MongoDB Community (and Enterprise) Edition includes a similar option [slowOpSampleRate](https://www.mongodb.com/docs/manual/reference/configuration-options/#mongodb-setting-operationProfiling.slowOpSampleRate). Please see [Profiling Rate Limit](https://docs.percona.com/percona-server-for-mongodb/8.0/rate-limit.html) for more information.
