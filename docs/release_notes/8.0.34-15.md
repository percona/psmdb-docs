# Percona Server for MongoDB {{ page.meta.version }} ({{date.8_0_34}})

[Installation](../install/index.md){.md-button}
[Upgrade from MongoDB Community](../install/upgrade-from-mongodb.md){.md-button}

We are pleased to announce **Percona Server for MongoDB {{ page.meta.version }}**, the drop-in replacement for MongoDB Community Edition. Percona Server for MongoDB supports MongoDB Community protocols and drivers and enhances it with [enterprise-grade features for free](../comparison.md), helping you meet your organization's requirements for high availability, reliability, and data security.

Percona Server for MongoDB **{{ page.meta.version }}** includes the improvements and bug fixes of:

- [MongoDB 8.0.34 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.0/#8034---sept-24-2026){:target="_blank"}.

- Supports protocols and drivers of MongoDB Community **8.0.34**.

## Upgrade recommendation

We recommend **upgrading to version {{ page.meta.version }}** to benefit from the backup and checkpoint fixes included in MongoDB 8.0.34.

## Improvements and bug fixes from upstream MongoDB

This release includes the following changes listed in the [MongoDB 8.0.34 patch release notes :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.0/#8034---sept-24-2026){:target="_blank"}.

### Bugs fixed

- [SERVER-98105 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-98105){:target="_blank"}: Fixed an issue that could occur when a backup ran at the same time as a drop operation. Cleanup of storage files pending deletion now pauses until the backup cursor closes.

- [WT-18353 :octicons-link-external-16:](https://jira.mongodb.org/browse/WT-18353){:target="_blank"}: Fixed an issue that could cause repeated server crashes during checkpoints when incremental backup was configured and a modified file's metadata lacked the `checkpoint_backup_info` field. The issue affected files whose metadata predated the introduction of this field.

For the complete upstream changelog, see [MongoDB 8.0.34 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.0-changelog/#8034-changelog){:target="_blank"}.
