# Percona Server for MongoDB {{ page.meta.version }} ({{date.7_0_48}})

[Installation](../install/index.md){.md-button}
[Upgrade](../install/minor-upgrade.md){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is a drop-in replacement for MongoDB Community Edition. It supports MongoDB Community protocols and drivers and provides [enterprise-grade features at no cost](../comparison.md).

This release includes the improvements and bug fixes from [MongoDB 7.0.48 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/7.0/#7048---nov-10-2026){:target="_blank"}.

## Upgrade recommendation

This release fixes multiple security vulnerabilities inherited from upstream MongoDB. We strongly recommend **upgrading to version {{ page.meta.version }}** as soon as possible.

See [Upgrade Percona Server for MongoDB](../install/minor-upgrade.md) for upgrade instructions.

## Security fixes from upstream MongoDB

The following entries describe upstream MongoDB security fixes. Severity follows MongoDB's CVSS 4.0 scores in the linked CVE records. Platform-specific entries retain their upstream scope and do not imply that Linux deployments are affected.

### Critical severity

- [SERVER-138119 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-138119){:target="_blank"}, [SERVER-138175 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-138175){:target="_blank"} [CVE-2026-118383 (Critical) :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-118383){:target="_blank"}: Fixed a use-after-free when a newly elected replica set primary completes catch-up. Unauthenticated requests could trigger a server crash or, under certain conditions, arbitrary code execution. The issue affects replica set members, including shard and config server members, but not standalone mongod instances.

- [SERVER-130681 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130681){:target="_blank"} ([CVE-2026-120808 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120808){:target="_blank"}): Fixed TLS certificate validation for outbound IPv6 connections on macOS with Apple SecureTransport. An attacker on the network path could use a self-signed certificate to intercept or alter traffic.

### High severity

- [CVE-2026-120828 (High) :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120828){:target="_blank"}: Fixed an issue where requests with unreachable read-concern timestamps left internal wait records allocated after the requests ended. An unauthenticated client could cause these records to accumulate, exhausting memory and making a replica set member unavailable.

- [SERVER-130268 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130268){:target="_blank"} ([CVE-2026-120804 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120804){:target="_blank"}): Fixed a credential-handle leak in MongoDB Enterprise for Windows. Repeated unauthenticated Kerberos requests could prevent further Kerberos authentication until the server was restarted.

- [SERVER-130261 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130261){:target="_blank"} ([CVE-2026-120806 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120806){:target="_blank"}): Fixed stale references left after dropping database roles. A user with database administrative privileges could recreate a role with different privileges, granting them to previously associated users without an explicit grant or audit event.

- [SERVER-130169 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130169){:target="_blank"} ([CVE-2026-120807 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120807){:target="_blank"}): Fixed an X.509 cluster authentication issue under a non-default configuration. User lookup errors could let a valid cluster-member certificate bypass membership checks and grant internal system privileges.

- [SERVER-132430 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132430){:target="_blank"} ([CVE-2026-120810 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120810){:target="_blank"}): Fixed an internal aggregation expression that allowed an authenticated user with read privileges to exhaust server memory through crafted requests, terminating `mongod`.

- [SERVER-132517 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132517){:target="_blank"} ([CVE-2026-120813 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120813){:target="_blank"}): Fixed an issue where a malicious client-side field-level encryption (CSFLE) schema could discard encryption metadata and leave fields in plaintext. Exploitation requires control over the schema delivered to the client.

- [SERVER-134872 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-134872){:target="_blank"} ([CVE-2026-120815 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120815){:target="_blank"}): Fixed a localhost-exception check that could grant administrative privileges to an unauthenticated local user, exposing data and credentials and allowing data modification or service disruption.

- [SERVER-135655 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135655){:target="_blank"} ([CVE-2026-120817 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120817){:target="_blank"}): Fixed a race condition during concurrent writes checked against a collection validator with geospatial operators. An authenticated user with write privileges could trigger the issue and crash the server.

- [SERVER-135727 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135727){:target="_blank"} ([CVE-2026-120818 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120818){:target="_blank"}): Fixed a use-after-free in server-side JavaScript during aggregation. An authenticated user, even without assigned roles, could submit a crafted request that exposed server memory and affected availability.

- [SERVER-136182 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-136182){:target="_blank"} ([CVE-2026-120822 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120822){:target="_blank"}): Fixed an authorization bypass in a replication-related administrative command. A user with backup and restore privileges could read or relocate collections outside their permitted scope.

- [SERVER-136505 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-136505){:target="_blank"} ([CVE-2026-120824 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120824){:target="_blank"}): Fixed a use-after-free during time series bucket validation. A user permitted to write directly to bucket documents could crash the server or, under certain conditions, execute arbitrary code.

### Medium severity

- [SERVER-135353 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135353){:target="_blank"} ([CVE-2026-120811 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120811){:target="_blank"}): Fixed a use-after-free in the classic query engine plan cache. Diagnostic commands from an authenticated user could expose server memory or, under certain conditions, crash the server.

### Low severity

- [SERVER-130498 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130498){:target="_blank"} ([CVE-2026-120805 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120805){:target="_blank"}): Fixed a Queryable Encryption authorization issue. A user with insert privileges could redirect metadata writes to another encrypted collection in the same database, bypassing permissions and potentially corrupting encrypted index state.

- [SERVER-135203 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135203){:target="_blank"} ([CVE-2026-120816 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120816){:target="_blank"}): Fixed an authorization issue in database change streams with `showSystemEvents`. A user with basic database read privileges could access restricted system collection contents.

For the complete upstream changelog, see [MongoDB 7.0.48 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/7.0-changelog/#7048-changelog){:target="_blank"}.
