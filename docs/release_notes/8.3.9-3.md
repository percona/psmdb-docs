# Percona Server for MongoDB {{ page.meta.version }} ({{date.8_3_9}})

[Installation](../install/index.md){.md-button}
[Upgrade from MongoDB Community](../install/upgrade-from-mongodb.md){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is an enhanced, source-available, and highly scalable database that is a fully compatible, drop-in replacement for MongoDB Community Edition.

Percona Server for MongoDB **{{ page.meta.version }}** includes the improvements and bug fixes of:

- [MongoDB 8.3.9 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.3/){:target="_blank"}.

- Supports protocols and drivers of MongoDB Community **8.3.9**.

## Upgrade recommendation

This release fixes one critical and 16 high-severity vulnerabilities affecting earlier Percona Server for MongoDB 8.3.x versions. We strongly recommend upgrading to version {{ page.meta.version }} as soon as possible.

## Security fixes from upstream MongoDB

This release fixes vulnerabilities inherited from upstream MongoDB. The severity categories below follow the upstream [CVSS scores :octicons-link-external-16:](https://nvd.nist.gov/vuln-metrics/cvss){:target="_blank"}.

### Critical severity

- [SERVER-131229 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131229){:target="_blank"} ([CVE-2026-82067 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82067){:target="_blank"}): Fixed an issue where improper case-sensitive configuration validation could leave authorization disabled when the server started. An unauthenticated network user could perform arbitrary administrative operations, compromising the confidentiality, integrity, and availability of the deployment.

### High severity

- [SERVER-124077 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-124077){:target="_blank"} ([CVE-2026-82052 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82052){:target="_blank"}): Fixed an issue in the `$regexFindAll` aggregation expression where an authenticated user could supply a regular expression that matched inside a multi-byte UTF-8 character. This could trigger an assertion and terminate `mongod`, resulting in a denial-of-service.

- [SERVER-130785 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130785){:target="_blank"} ([CVE-2026-82053 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82053){:target="_blank"}): Fixed an issue in LDAP authorization where pooled connections could retain a stale authentication identity. In affected configurations, an authenticated user could receive unintended LDAP role assignments and elevated privileges.

- [SERVER-130901 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130901){:target="_blank"} ([CVE-2026-82054 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82054){:target="_blank"}): Fixed insufficient resource limits in the JSON Pointer parser used for `$jsonSchema` query filters. Concurrent crafted requests from an authenticated user could exhaust heap memory and terminate `mongod`, resulting in a denial-of-service.

- [SERVER-130202 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130202){:target="_blank"} ([CVE-2026-82055 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82055){:target="_blank"}): Fixed an issue in `2dsphere` index key generation where an authenticated user with write access could insert crafted GeoJSON data that left geometry state partially initialized. Subsequent index processing could dereference a null pointer and terminate `mongod`.

- [SERVER-130495 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130495){:target="_blank"} ([CVE-2026-82057 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82057){:target="_blank"}): Fixed an issue where a user with `readWrite` privileges could create a collection with an incompatible WiredTiger storage configuration. Reading the collection could cause type confusion and terminate `mongod`, while the persistent configuration could continue causing failures after a restart.

- [SERVER-130926 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130926){:target="_blank"} ([CVE-2026-82058 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82058){:target="_blank"}): Fixed an issue in `$jsonSchema` validation error generation where a user with `readWrite` privileges could submit a BSON array with a malformed numeric field name. Unsafe numeric conversion could raise an unhandled exception and terminate `mongod`.

- [SERVER-130907 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130907){:target="_blank"} ([CVE-2026-82061 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82061){:target="_blank"}): Fixed a use-after-free issue in query execution memory tracking. An authenticated user with read privileges could trigger a write to released heap memory, potentially causing memory corruption or terminating the server process.

- [SERVER-131138 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131138){:target="_blank"} ([CVE-2026-82062 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82062){:target="_blank"}): Fixed an authorization issue in `applyOps` where an authenticated user with elevated internal privileges could bypass a disabled feature gate. This could permit writes to arbitrary internal storage tables, including metadata or data belonging to other collections.

- [SERVER-130759 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130759){:target="_blank"} ([CVE-2026-82064 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82064){:target="_blank"}): Fixed an assertion in read-concern processing that could be reached without authentication on certain replica set members. An unauthenticated network user could terminate the affected server process and cause a denial-of-service.

- [SERVER-131420 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131420){:target="_blank"} ([CVE-2026-82065 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82065){:target="_blank"}): Fixed insufficient validation of storage configuration options supplied during collection creation. An authenticated user with collection creation privileges could persist invalid metadata that caused fatal assertions, propagated to other members, and required manual intervention to restore service.

- [SERVER-131326 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131326){:target="_blank"} ([CVE-2026-82068 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82068){:target="_blank"}): Fixed an issue where an authenticated user with write privileges could submit crafted retryable-write commands that persisted a fatal assertion state. This could cause repeated crashes after restart and propagate the failure to other nodes in a sharded cluster.

- [SERVER-131423 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131423){:target="_blank"} ([CVE-2026-82070 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82070){:target="_blank"}): Fixed insufficient credential redaction in a diagnostic reporting interface. An authenticated user with monitoring privileges could view cleartext credentials from concurrent administrative operations and potentially impersonate other users, including privileged accounts.

- [SERVER-131860 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131860){:target="_blank"} ([CVE-2026-82071 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82071){:target="_blank"}): Fixed insufficient validation of WiredTiger configuration options supplied during collection creation. An authenticated user with write privileges could cause an out-of-bounds memory write, potentially terminating the server or executing unintended code.

- [SERVER-132125 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132125){:target="_blank"} ([CVE-2026-82073 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82073){:target="_blank"}): Fixed an issue in the aggregation framework where an external client could set an internal command parameter when Atlas Search features were used. An authenticated user with limited read privileges could bypass view authorization and read data from unauthorized collections.

- [SERVER-132650 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132650){:target="_blank"} ([CVE-2026-82075 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82075){:target="_blank"}): Fixed uncontrolled CPU consumption in the `mongos` connection-monitoring request path. An unauthenticated client with network access to the router could degrade or deny service to legitimate clients.

- [SERVER-128253 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-128253){:target="_blank"} ([CVE-2026-82076 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82076){:target="_blank"}): Fixed an integer overflow in the query planner that allowed a user with database-level read and write privileges to bypass an internal resource limit. A crafted query could cause unbounded memory consumption and terminate the server process.

### Medium severity

- [SERVER-130306 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130306){:target="_blank"} ([CVE-2026-82056 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82056){:target="_blank"}): Fixed a race condition in text-index query parsing during upsert retries. A user with `readWrite` privileges could combine text searches with concurrent index operations to trigger a heap use-after-free and terminate the server process.

- [SERVER-130571 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130571){:target="_blank"} ([CVE-2026-82059 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82059){:target="_blank"}): Fixed an internal aggregation expression that was accessible to authenticated users. A user with read privileges could supply a malformed index specification that triggered an assertion and, in certain builds, terminated `mongod`.

- [SERVER-131870 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131870){:target="_blank"} ([CVE-2026-82063 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82063){:target="_blank"}): Fixed a use-after-free issue in cursor management. Under specific timing conditions, an authenticated user could cause cursor cleanup to dereference a released resource and terminate the server process.

- [SERVER-131562 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131562){:target="_blank"} ([CVE-2026-82066 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82066){:target="_blank"}): Fixed an out-of-bounds heap read in the query planner. An authenticated user with database read and write privileges could submit crafted queries that exposed portions of process memory through diagnostic query statistics.

- [SERVER-132835 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132835){:target="_blank"} ([CVE-2026-82069 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82069){:target="_blank"}): Fixed improper redaction of Atlas Search query literals in query statistics generated by `mongos`. A user with monitoring privileges could access sensitive query text from other users' operations.

### Low severity

- [SERVER-131202 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131202){:target="_blank"} ([CVE-2026-82060 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82060){:target="_blank"}): Fixed insufficient validation of operator-shaped shard key values inserted by authenticated users. When change streams used `updateLookup`, these values could alter internal post-image queries, causing incorrect post-image documents or non-resumable errors.
