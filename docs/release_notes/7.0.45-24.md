# Percona Server for MongoDB {{ page.meta.version }} ({{date.7_0_45}})

[Installation](../install/index.md){.md-button}
[Upgrade from MongoDB Community](../install/upgrade-from-mongodb.md){.md-button}

We are pleased to announce **Percona Server for MongoDB {{ page.meta.version }}**, the drop-in replacement for MongoDB Community Edition. Percona Server for MongoDB supports MongoDB Community protocols and drivers and enhances it with [enterprise-grade features for free](../comparison.md), helping you meet your organization's requirements for high availability, reliability, and data security.

Percona Server for MongoDB **{{ page.meta.version }}** includes the improvements and bug fixes of:

- [MongoDB 7.0.45 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/v7.0/release-notes/7.0/#7045---sept-28-2026){:target="_blank"}.

- Supports protocols and drivers of MongoDB Community **7.0.45**.

## Upgrade recommendation

We recommend upgrading to **version {{ page.meta.version }}** to benefit from the bug fixes included in MongoDB 7.0.45.

## Changelog

### Improvement

- [PSMDB-1944](https://perconadev.atlassian.net/browse/PSMDB-1944): Separated MongoDB Database Tools package builds from PSMDB server package builds. This allows tool updates, including security fixes, to be prepared independently without rebuilding the server packages.

## Bug fixes from upstream MongoDB

This release includes the following changes listed in the [MongoDB 7.0.45 patch release notes :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/7.0/#7045---sept-28-2026){:target="_blank"}.

### Bugs fixed

- [SERVER-104343 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-104343){:target="_blank"}: Fixed an issue where the `unsupportedSyncSource` server parameter could trigger an assertion failure.

- [SERVER-107966 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-107966){:target="_blank"}: Fixed an issue where a ping monitor in the replica set monitor could become disabled and fail to resume monitoring.

- [SERVER-119766 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-119766){:target="_blank"}: Fixed an issue with concurrent access to the `oplogFetcherHighestFetchedOptime` metric that caused a data race.

- [SERVER-128392 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-128392){:target="_blank"}: Fixed an issue where inserting a duplicate document into a clustered collection could return a KeyString format error when the `_id` contained a `Decimal128` value.

- [SERVER-132246 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132246){:target="_blank"}: Fixed an issue where the default `minWaitForStreamingHelloMillis` value caused incompatibility with drivers that follow the MongoDB driver specification.

For the complete upstream changelog, see [MongoDB 7.0.45 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/7.0-changelog/#7045-changelog){:target="_blank"}.
