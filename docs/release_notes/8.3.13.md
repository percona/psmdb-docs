# Percona Server for MongoDB {{ page.meta.version }} ({{date.8_3_13}})

[Installation](../install/index.md){.md-button}
[Upgrade](../install/minor-upgrade.md){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is a drop-in replacement for MongoDB Community Edition. It supports MongoDB Community protocols and drivers and provides [enterprise-grade features at no cost](../comparison.md).

This release includes the improvements and bug fixes from [MongoDB 8.3.13 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.3/#8313---sept-24-2026){:target="_blank"}.

## Upgrade considerations

!!! warning "Technical Preview"

    Percona Server for MongoDB {{ page.meta.version }} is available as a technical preview. Use this release for testing purposes only, not in production environments.

See [Minor upgrade of Percona Server for MongoDB](../install/minor-upgrade.md) for upgrade instructions.

## Improvements and bug fixes from upstream MongoDB

The [MongoDB 8.3.13 patch release notes :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.3/#8313---sept-24-2026){:target="_blank"} list the following change:

### Bugs fixed

* [SERVER-127294 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-127294){:target="_blank"}: Fixed a race condition in an internal network-interface test.

Find the full list of changes in the [MongoDB 8.3.13 changelog :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.3-changelog/#8313-changelog){:target="_blank"}.
