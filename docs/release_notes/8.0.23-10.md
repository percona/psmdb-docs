Percona Server for MongoDB 8.0.23-10 is an enhanced, source-available, and highly-scalable database that is a
fully-compatible, drop-in replacement for MongoDB Community Edition.

Percona Server for MongoDB **8.0.23-10** includes the improvements and bug fixes of: 

- [MongoDB 8.0.23 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.0/#8.0.23---may-12--2026){:target="_blank"}


It supports protocols and drivers of MongoDB Community **8.0.23**.

## Bugs

### Unique index violation in sharded clusters

[SERVER-85346 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-85346){:target="_blank"}: Fixed an issue where unique indexes using a non-simple collation in sharded collections could incorrectly allow logically duplicate values across different shards when the shard key matched, or was a strict prefix of, the index key pattern.

For example, in a collection sharded on `{ a: 1 }` with a case-insensitive unique index, documents containing `{ a: "YES" }` and `{ a: "yes" }` could be inserted on different shards even though the values are considered equal under the configured collation.

This issue could cause uniqueness constraints to be enforced incorrectly, but it did not result in data loss or sharding metadata corruption.

#### Affected PSMDB versions

- 5.0.x 
- 6.0.x
- 7.0.0 – 7.0.31-17
- 8.0.4 – 8.0.19-7

#### Resolution

Upgrade to one of the following versions:

- PSMDB 7.0.32-18
- PSMDB 8.0.21-9 or later

!!! note
    We **do not** provide fixes for the 5.0 or 6.0 release lines. We recommend you to upgrade to a supported version.


### Default read/write concerns ignored on sharded connections

[SERVER-111031 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-111031){:target="_blank"}: Fixed an issue where cluster-wide default write concerns were ignored when connecting directly to shard nodes instead of through mongos. 

In some cases, writes could default to { `w: 1` } instead of { `w: "majority"` }, increasing the risk of data loss during rollback scenarios.

#### Affected PSMDB versions

- 5.0.x
- 6.0.x
- 7.0.0
- 7.0.31-17
- 8.0.4 – 8.0.19-7

#### Resolution

- Upgrade to Upgrade to one of the following versions:

    - PSMDB 7.0.32-18
    - 8.0.20-8 or later.

- Ensure all connections go through `mongos`. 

- If a direct shard connection is mandatory, explicitly set {`w: "majority"`} in the connection string.

!!! note
    We **do not** provide fixes for the 5.0 or 6.0 release lines. We recommend you to upgrade to a supported version.


## Security updates: CVE fixes from upstream MongoDB

This release includes upstream MongoDB security fixes for the following vulnerabilities:

### High severity

- [SERVER-126021 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-126021){:target="_blank"} **(CVE-2026-8053)**: Fixed a vulnerability in the time-series collection implementation that could allow an authenticated user with write privileges to trigger an out-of-bounds memory write in the `mongod` process. Under certain conditions, this issue could lead to arbitrary code execution.
     

- [SERVER-122449 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-122449){:target="_blank"} **(CVE-2026-8199)**: Fixed an issue where an authenticated user could cause excessive memory consumption during Abstract Syntax Tree (AST) processing of the following operators:

    - `$bitsAllSet`
    - `$bitsAnySet`
    - `$bitsAllClear`
    - `$bitsAnyClear`

    This could lead to increased memory pressure and potential service unavailability due to out-of-memory (OOM) conditions.

- [SERVER-121610 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-121610){:target="_blank"} **(CVE-2026-8336)**: Fixed a vulnerability where an authenticated user could crash the mongod process through specially crafted use of `$_internalJsEmit`, or by manipulating the `mapReduce` command’s `map` function together with server-side JavaScript execution features such as:

    - `$where`
    - `$function`
    - the `mapReduce` reduce stage

### Medium severity

- [SERVER-122032 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-122032){:target="_blank"} **(CVE-2026-8201)**: Fixed a use-after-free vulnerability in MongoDB’s Field-Level Encryption (FLE) query analysis component affecting client-side deployments using `mongocryptd` and `crypt_shared`. A specially crafted FLE-related query could cause unexpected behavior or client instability.

- [SERVER-120668 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-120668){:target="_blank"} **(CVE-2026-8202)**: Fixed an issue in the `$trim`, `$ltrim`, and `$rtrim` aggregation operators where specially crafted inputs could cause excessive CPU consumption. 

    An authenticated user with aggregation privileges could exploit this issue to impact database performance and availability.

- [SERVER-121895 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-121895){:target="_blank"} **(CVE-2026-8200)**: Fixed an issue where schema validation failures could result in unredacted user data being written to server logs. 

    Under certain insert or update operations that violated schema validation rules, sensitive information could be exposed in local log files.


### Upgrade recommendations

To receive these security fixes, upgrade to one of the following versions:

- Percona Server for MongoDB 8.0.23-10
- Percona Server for MongoDB 7.0.34-19

Perform a rolling upgrade where appropriate to minimize service disruption.

If you are running Percona Server for MongoDB 5.0 or 6.0 and cannot upgrade to a supported major version, contact Percona Support for assistance. Backport requests are evaluated on a case-by-case basis.

### Affected versions

For the 8.0 release line, these vulnerabilities affect:

- Percona Server for MongoDB versions earlier than 8.0.23-10
MongoDB Community Edition versions earlier than 8.0.23

- If you are running Percona Server for MongoDB 7.0, 6.0, or 5.0, refer to the version-specific upgrade and support guidance above for details about the impact and available upgrade options.
