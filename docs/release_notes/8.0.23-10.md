Percona Server for MongoDB 8.0.23-10 is an enhanced, source-available, and highly-scalable database that is a
fully-compatible, drop-in replacement for MongoDB Community Edition.

Percona Server for MongoDB **8.0.23-10** includes the improvements and bug fixes of: 

- [MongoDB 8.0.23 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/8.0/#8.0.23---may-12--2026){:target="_blank"}


It supports protocols and drivers of MongoDB Community **8.0.23**.

## Security updates: CVE fixes from upstream MongoDB

This release includes upstream MongoDB security fixes for the following vulnerabilities:

### High severity

- [SERVER-126021 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-126021){:target="_blank"} **(CVE-2026-8053)**: Fixed an issue in MongoDB Server's time-series collection implementation that allowed an authenticated user with database write privileges to trigger an out-of-bounds memory write in the mongod process. The issue resulted from an inconsistency in the internal `field-name-to-index` mapping within the time-series bucket catalog. Under certain conditions, this resulted in arbitrary code execution. 

- [SERVER-122449 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-122449){:target="_blank"} **(CVE-2026-8199)**: We fixed an issue where authenticated users could trigger excessive memory consumption using specific bitwise operators (`$bitsAllSet, $bitsAnySet, $bitsAllClear`, and `$bitsAnyClear`). This occurred during the processing of the Abstract Syntax Tree (AST) and could lead to system instability or service unavailability due to out-of-memory (OOM) errors.

- [SERVER-121610 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-121610){:target="_blank"} **(CVE-2026-8336)**: A vulnerability was identified in MongoDB Server where invoking `$_internalJsEmit` (an internal function not intended for direct use) or crafting a `mapreduce` command’s map function in a certain way could destabilize the server. When combined with subsequent use of the server-side JavaScript engine (via `$where, $function`, or the `mapreduce` reduce stage), an authenticated user could trigger a crash in the mongod process. The issue has been resolved now.

### Medium severity

- [SERVER-122032 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-122032){:target="_blank"} **(CVE-2026-8201)**: Resolved a use-after-free vulnerability in MongoDB’s **Field-Level Encryption** (FLE) query analysis component affecting client-side deployments using `mongocryptd` and `crypt_shared`. An attacker able to manipulate the structure of an FLE-related query could trigger unexpected behavior or cause the client to become unstable.

- [SERVER-120668 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-120668){:target="_blank"} **(CVE-2026-8202)**: Resolved an issue in the MongoDB aggregation operators `$trim`, `$ltrim`, and `$rtrim` where specially crafted inputs using densely populated character masks and large strings could cause excessive CPU consumption. An authenticated user with aggregation permissions could exploit this issue to keep CPU utilization at 100% for an extended period of time, potentially impacting database performance and availability.

[SERVER-121895 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-121895){:target="_blank"} **(CVE-2026-8200)**: Resolved an issue where server log messages generated during schema validation failures could include unredacted user data. When schema validation was enabled on a collection, certain insert or update operations that violated the schema could cause sensitive information to appear in local server logs.

### Affected versions

These vulnerabilities affect the following versions of MongoDB Community Edition and Percona Server for MongoDB:

- All Percona Server for MongoDB 8.0.x versions
- MongoDB Community 8.0 versions prior to 8.0.23
