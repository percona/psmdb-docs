# Percona Server for MongoDB {{ page.meta.version }} ({{ date[(release.split('-')[0].replace('.', '') | int)] }})

[Installation](../install/index.md){.md-button}
[Upgrade from MongoDB Community](../install/upgrade-from-mongodb.md){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is an enhanced, source-available, and highly scalable database that is a fully compatible, drop-in replacement for MongoDB Community Edition.

Percona Server for MongoDB **{{ page.meta.version }}** includes the improvements and bug fixes of:

- [MongoDB 8.0.32 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/v8.0/release-notes/8.0/){:target="_blank"}.

- Supports protocols and drivers of MongoDB Community **8.0.32**.

## Upgrade recommendation

This release fixes one critical, 12 high-severity, and four medium-severity vulnerabilities inherited from upstream MongoDB. We strongly recommend upgrading to version {{ page.meta.version }} as soon as possible.

## Security fixes from upstream MongoDB

This release fixes vulnerabilities inherited from upstream MongoDB. The severity categories below follow the upstream [CVSS scores :octicons-link-external-16:](https://nvd.nist.gov/vuln-metrics/cvss){:target="_blank"}.

### Critical severity

- [SERVER-131229 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131229){:target="_blank"} ([CVE-2026-82067 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82067){:target="_blank"}): Fixed improper case handling in configuration validation that could allow MongoDB Server to start with authorization disabled. This could leave the server accessible without the intended authorization controls.

### High severity

- [SERVER-134063 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-134063){:target="_blank"} ([CVE-2026-89099 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-89099){:target="_blank"}): Fixed a race condition in MongoDB Server's document value layer where concurrent server threads could access the same internal memory without synchronization. An authenticated user with ordinary read-write privileges could trigger the issue over the normal client protocol, causing server termination and potentially corrupting process memory with user-influenced content.

- [SERVER-128253 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-128253){:target="_blank"} ([CVE-2026-82076 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82076){:target="_blank"}): Fixed an integer overflow in the query planner's scan-count calculation. An authenticated client could submit a crafted query with large `$in` arrays that triggered unbounded memory allocation, making `mongod` unavailable.

- [SERVER-132650 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132650){:target="_blank"} ([CVE-2026-82075 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82075){:target="_blank"}): Fixed uncontrolled resource consumption in the MongoDB sharded cluster router's pre-authentication request path. An unauthenticated client could exhaust resources and cause a denial of service on `mongos`.

- [SERVER-132275 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132275){:target="_blank"} ([CVE-2026-82074 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82074){:target="_blank"}): Fixed an authorization issue in the aggregation framework where `$lookup` accepted multiple `pipeline` arguments. This could allow an authenticated user to read collection data without the required authorization.

- [SERVER-131423 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131423){:target="_blank"} ([CVE-2026-82070 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82070){:target="_blank"}): Fixed inconsistent redaction in the MongoDB Server diagnostic reporting interface. This could expose protected credentials in diagnostic output to an authenticated user.

- [SERVER-131326 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131326){:target="_blank"} ([CVE-2026-82068 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82068){:target="_blank"}): Fixed an issue where crafted retryable write commands containing repeated statement IDs could trigger a fatal assertion. An authenticated user with write privileges could crash the server and cause a denial of service.

- [SERVER-131420 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131420){:target="_blank"} ([CVE-2026-82065 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82065){:target="_blank"}): Fixed insufficient validation of storage configuration options. An authenticated user could persist invalid metadata that prevented the server from operating normally, causing a persistent denial of service.

- [SERVER-130759 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130759){:target="_blank"} ([CVE-2026-82064 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82064){:target="_blank"}): Fixed an assertion failure in read concern processing on replica set members. An unauthenticated network client could trigger the failure and cause a denial of service.

- [SERVER-130926 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130926){:target="_blank"} ([CVE-2026-82058 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82058){:target="_blank"}): Fixed an unhandled exception while generating JSON Schema validation errors. An authenticated user could submit crafted input that terminated `mongod`, causing a denial of service.

- [SERVER-130901 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130901){:target="_blank"} ([CVE-2026-82054 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82054){:target="_blank"}): Fixed missing resource limits in the JSON Pointer parser used by `$jsonSchema` query filters. An authenticated user could submit crafted filters that amplified memory consumption and terminated `mongod` through resource exhaustion.

- [SERVER-130785 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130785){:target="_blank"} ([CVE-2026-82053 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82053){:target="_blank"}): Fixed stale authentication identities in pooled LDAP connections. Authorization queries could run under the wrong LDAP identity, resulting in incorrect role assignments and unintended privilege elevation.

- [SERVER-124077 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-124077){:target="_blank"} ([CVE-2026-82052 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82052){:target="_blank"}): Fixed an issue in `$regexFindAll` when byte matching multi-byte UTF-8 characters. An authenticated user able to run aggregation queries could crash `mongod`, causing a denial of service.

### Medium severity

- [SERVER-131562 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131562){:target="_blank"} ([CVE-2026-82066 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82066){:target="_blank"}): Fixed a heap out-of-bounds read in the query planning component. A crafted query could cause the server process to terminate, resulting in a denial of service.

- [SERVER-131870 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-131870){:target="_blank"} ([CVE-2026-82063 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82063){:target="_blank"}): Fixed a use-after-free in cursor management. An authenticated user could trigger the memory-safety issue and terminate the server process, causing a denial of service.

- [SERVER-130571 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130571){:target="_blank"} ([CVE-2026-82059 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82059){:target="_blank"}): Fixed an internal aggregation expression that was incorrectly exposed to external clients. An authenticated user could invoke it to trigger an assertion failure and cause a denial of service.

- [SERVER-130306 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130306){:target="_blank"} ([CVE-2026-82056 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-82056){:target="_blank"}): Fixed a race condition in text index query parsing that could cause a heap use-after-free during concurrent text search and index management operations. An authenticated user with `readWrite` privileges could crash the server and cause a denial of service.
