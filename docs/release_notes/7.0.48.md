# Percona Server for MongoDB {{ page.meta.version }} ({{date.7_0_48}})

[Installation](../install/index.md){.md-button}
[Upgrade](../install/minor-upgrade.md){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is a drop-in replacement for MongoDB Community Edition. It supports MongoDB Community protocols and drivers and provides [enterprise-grade features at no cost](../comparison.md).

This release includes the improvements and bug fixes from [MongoDB 7.0.48 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/7.0/#7048---nov-10-2026){:target="_blank"}.

## Upgrade recommendation

This release fixes multiple security vulnerabilities inherited from upstream MongoDB. We strongly recommend **upgrading to version {{ page.meta.version }}** as soon as possible.

See [Upgrade Percona Server for MongoDB](../install/minor-upgrade.md) for upgrade instructions.

## Improvements and bug fixes from upstream MongoDB

The following changes are highlighted in these upstream patch releases. Security fixes are listed separately in [Security fixes from upstream MongoDB](#security-fixes-from-upstream-mongodb).

### Improvements

- [SERVER-108215 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-108215){:target="_blank"}: Added limits on active multi-document transactions to control the performance impact of large numbers of idle transactions.

- [SERVER-132098 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132098){:target="_blank"}: Updated the bundled time zone library and data to version 2026e.

### Bugs fixed

- [SERVER-98105 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-98105){:target="_blank"}: Fixed an issue that occurred when a backup ran at the same time as a drop operation. Cleanup of storage files pending deletion now pauses until the backup cursor closes.

## Security fixes from upstream MongoDB

The following entries describe upstream MongoDB security fixes. Severity follows MongoDB's CVSS 4.0 scores in the linked CVE records. Platform-specific entries retain their upstream scope and do not imply that Linux deployments are affected.

### Critical severity

- [SERVER-138119 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-138119){:target="_blank"}, [SERVER-138175 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-138175){:target="_blank"} ([CVE-2026-118383 (Critical) :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-118383){:target="_blank"}, [CVE-2026-120828 (High) :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120828){:target="_blank"}): Unauthenticated requests could trigger a use-after-free during primary catch-up, causing a crash or, under certain conditions, arbitrary code execution. Separately, requests with unreachable read-concern timestamps could leave wait records allocated and exhaust memory. Both issues affect replica set members, including shard and config server members; standalone instances are not affected by these issues.

- [SERVER-130681 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130681){:target="_blank"} ([CVE-2026-120808 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120808){:target="_blank"}): On macOS with Apple SecureTransport, outbound TLS connections to IPv6 peers could bypass certificate trust validation. An attacker on the network path could use a self-signed certificate to intercept or alter the traffic.

### High severity

- [SERVER-130268 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130268){:target="_blank"} ([CVE-2026-120804 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120804){:target="_blank"}): On MongoDB Enterprise for Windows, repeated unauthenticated Kerberos requests could leak credential handles until further Kerberos authentication fails. Recovery requires a server restart.

- [SERVER-130261 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130261){:target="_blank"} ([CVE-2026-120806 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120806){:target="_blank"}): Dropping database roles could leave stale user and role references. Recreating a role with different privileges could then grant those privileges to previously associated users without an explicit grant or audit event. Exploitation requires database administrative privileges.

- [SERVER-130169 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130169){:target="_blank"} ([CVE-2026-120807 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120807){:target="_blank"}): With a non-default X.509 cluster authentication configuration, user lookup errors could let a holder of a valid cluster-member certificate bypass the membership guard and gain internal system privileges.

- [SERVER-132430 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132430){:target="_blank"} ([CVE-2026-120810 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120810){:target="_blank"}): An authenticated user with read privileges could exhaust server memory through crafted aggregation requests using an internal expression, causing `mongod` to terminate.

- [SERVER-132517 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-132517){:target="_blank"} ([CVE-2026-120813 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120813){:target="_blank"}): A malicious client-side field-level encryption (CSFLE) schema could cause encryption metadata to be discarded, leaving fields intended for encryption stored in plaintext. Exploitation requires control over the schema delivered to the client, such as through an untrusted server or interception.

- [SERVER-134872 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-134872){:target="_blank"} ([CVE-2026-120815 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120815){:target="_blank"}): An incorrect localhost-exception check could let an unauthenticated user with local access obtain administrative privileges, exposing data and credentials and allowing data modification or service disruption.

- [SERVER-135655 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135655){:target="_blank"} ([CVE-2026-120817 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120817){:target="_blank"}): Concurrent writes checked against a collection validator with geospatial query operators could trigger a race condition and crash the server. Exploitation requires an authenticated user with write privileges.

- [SERVER-135727 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135727){:target="_blank"} ([CVE-2026-120818 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120818){:target="_blank"}): An authenticated user, even without assigned roles, could submit a crafted aggregation request that reads freed memory through server-side JavaScript. This could disclose server memory and affect availability.

- [SERVER-136182 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-136182){:target="_blank"} ([CVE-2026-120822 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120822){:target="_blank"}): A user with backup and restore privileges could bypass authorization checks in a replication-related administrative command to read or relocate collections outside their permitted scope.

- [SERVER-136505 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-136505){:target="_blank"} ([CVE-2026-120824 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120824){:target="_blank"}): A user permitted to write directly to time series bucket documents could trigger a use-after-free during validation, causing a crash or, in some circumstances, arbitrary code execution.

### Medium severity

- [SERVER-135353 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135353){:target="_blank"} ([CVE-2026-120811 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120811){:target="_blank"}): A use-after-free in the classic query engine plan cache could expose server memory through diagnostic commands issued by an authenticated user. Under certain conditions, it could also crash the server.

### Low severity

- [SERVER-130498 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-130498){:target="_blank"} ([CVE-2026-120805 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120805){:target="_blank"}): A user with insert privileges could redirect Queryable Encryption metadata writes to another encrypted collection in the same database, bypassing collection permissions and potentially corrupting encrypted index state.

- [SERVER-135203 :octicons-link-external-16:](https://jira.mongodb.org/browse/SERVER-135203){:target="_blank"} ([CVE-2026-120816 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-120816){:target="_blank"}): A user with basic database read privileges could use a database change stream with `showSystemEvents` to read restricted system collection contents that direct reads would deny.
