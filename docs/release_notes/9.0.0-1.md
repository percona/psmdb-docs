# Percona Server for MongoDB {{ page.meta.version }} ({{date.9_0_0}})

[Installation](../install/index.md){.md-button}
[Upgrade](https://www.mongodb.com/docs/manual/release-notes/9.0-upgrade-standalone/){.md-button}

Percona Server for MongoDB {{ page.meta.version }} is a new major version and a drop-in replacement for MongoDB Community Edition. It supports MongoDB Community protocols and drivers and provides [enterprise-grade features at no cost](../comparison.md).

This release includes the improvements and bug fixes from [MongoDB 9.0.0 Community Edition :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/9.0/#900---sept-28-2026){:target="_blank"}.

## Upgrade considerations

Review the [MongoDB 9.0 compatibility changes :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/9.0-compatibility/){:target="_blank"} and test your applications before upgrading. Queries and `$lookup` stages that compare dotted paths to `null` can return different results when those paths traverse arrays. Server-side JavaScript local `Date` operations now use UTC rather than the host time zone.

The upstream upgrade path requires an 8.0 or 8.3 deployment and compatible drivers. See the [MongoDB 9.0 upgrade procedure :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/9.0-upgrade-standalone/){:target="_blank"}, including its links to replica set and sharded cluster procedures. For migration from MongoDB Community Edition, see [Upgrade from MongoDB Community](../install/upgrade-from-mongodb.md).

Review your Percona Memory Engine configuration. The engine now inherits WiredTiger options except those overridden by `storage.inMemory` settings. Inherited settings that were previously reset, including compression settings, can change behavior after upgrading.

## Release Highlights

In addition to the [upstream improvements](#upstream-improvements), this release includes the following Percona Server for MongoDB improvements:

### LDAP user-to-DN caching and monitoring

LDAP user-to-DN mapping results are cached to reduce repeated LDAP searches during authentication and authorization. Configure the entry lifetime with `ldapUserToDNCacheTTLSeconds` (default: `30` seconds) and the maximum number of entries with `ldapUserToDNCacheSize` (default: `10000`). Both parameters can be changed at startup or runtime; setting either to `0` disables caching.

The `ldap.userToDNCache` document in `serverStatus` reports cache configuration, usage, hits, misses, and invalidations. Use these metrics to assess cache sizing and diagnose LDAP lookup activity. See [LDAP parameters and cache monitoring](../ldap-parameters.md).

### Percona Memory Engine configuration inheritance

The Percona Memory Engine preserves WiredTiger options during initialization and applies its own settings as overrides. This avoids resetting options to constructor values that differ from configured or documented defaults. See [Percona Memory Engine](../inmemory.md).

### Upstream Improvements

MongoDB 9.0 introduces the following changes:

#### Workload management

* A per-operation memory limit bounds query memory use. The default is the greater of 1 GB or 20% of available server memory; operations exceeding it fail. Existing per-stage limits remain in effect.
* `maxConcurrentMultiDocumentTransactions` limits concurrent external-client transactions, defaulting to `10000`. Additional transactions receive `TooManyOpenTransactions`.

#### Developer experience

* `$queryStats` samples read and write operations by default, including `insert`, `update`, and `delete` commands.
* Time series collections use a single namespace for compressed bucket data and support `renameCollection`.

#### Security improvements

* Server-side JavaScript uses a WebAssembly-based engine for stronger isolation. `$accumulator`, `$function`, and `$where` are no longer deprecated.
* Queryable Encryption supports generally available prefix, suffix, and substring queries on encrypted strings. Using these queries with `mongosh` requires the Automatic Encryption Shared Library 9.0 or later.

Find the full list of changes in the [MongoDB 9.0 Community Edition release notes :octicons-link-external-16:](https://www.mongodb.com/docs/manual/release-notes/9.0/){:target="_blank"}.

## Changelog

### New Features

* [PSMDB-2003](https://perconadev.atlassian.net/browse/PSMDB-2003): Added LDAP user-to-DN mapping caching with configurable entry lifetime and cache size to reduce repeated LDAP searches. The cache is cleared when relevant LDAP settings change at runtime.

### Improvements

* [PSMDB-1832](https://perconadev.atlassian.net/browse/PSMDB-1832): Improved Percona Memory Engine initialization by preserving WiredTiger options except those overridden by the engine's own configuration.
* [PSMDB-2038](https://perconadev.atlassian.net/browse/PSMDB-2038): Added `ldap.userToDNCache` metrics to `serverStatus` so operators can monitor cache usage, hits, misses, and invalidations.

### Fixed Bugs

* [PSMDB-1766](https://perconadev.atlassian.net/browse/PSMDB-1766): Fixed an issue that prevented the background LDAP user-cache invalidation thread from starting, so changes to LDAP roles were not reflected after `ldapUserCacheInvalidationInterval`.
* [PSMDB-1937](https://perconadev.atlassian.net/browse/PSMDB-1937): Fixed an issue that caused builds from source trees without a `.git` directory to fail.
* [PSMDB-2200](https://perconadev.atlassian.net/browse/PSMDB-2200): Fixed an issue that caused statically linked builds to fail with duplicate symbols from conflicting copies of `s2n-tls`.
