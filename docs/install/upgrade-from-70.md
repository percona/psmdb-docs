# Upgrade from Percona Server for MongoDB 7.0 to 8.0

For the 7.0-to-8.0 procedure, see the [8.0 upgrade guide](https://docs.percona.com/percona-server-for-mongodb/8.0/install/upgrade-from-70.html).

To upgrade an 8.0 deployment, follow [Upgrade from 8.0 to {{psmdb_version}}](upgrade-from-80.md).
Upgrade 7.0 deployments to 8.0 before you proceed to {{psmdb_version}}.
